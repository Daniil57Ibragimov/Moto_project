В файле 0_Parsing_drom.ipynb находится который,использовался для парсинга данных с сайта drom.ru

В файле 0_drom.csv исходный датасет, который поулчился после парсинга данных

В файле 1_Data_cleaning.ipynb проводится первичная обработка данных, предшествующая непосредственному анализу.

В файле 1_drom_cleaned.csv содержится обработанный датасет, после преобразований в 1_Data_cleaning.ipynd

В файле 2_Data_Descripton.ipynb содержится описание датасета и шаги с анализом описательных статистик и графическим анализом переменных

В файле 3_Lin_reg.ipynb содержится построение линейной эконометрической модели согласно п.3 задания для проектов 1 типа. Также приложен файл 3.1_Lin_reg_draft.ipynb, в нем содержится анализ моделей без константы, но т.к. этот вариант дал более плохие результаты, в отчете не отражается и приводится справочно. 

В файле 4_Logit-model.ipynb содержится построение логит-модели согласно п.4 адания для проектов 1 типа

В файле Проект ЭКМ приведен итоговый отчет. Также загружается и word файл из-за ограничения на количество страниц, приложения получились очень сжатыми. В исходном документе их можно расширить и посмотреть в нормальном разрешении.
